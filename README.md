# Regresion-vivienda-Colombia

🏠 Predicción de Vivienda en Colombia
proyecto utiliza Inteligencia Artificial (Regresión Lineal Simple) para analizar y predecir el precio de apartamentos en Colombia basándose en su área en metros cuadrados.

📊 Proyecto

El objetivo principal es encontrar la relación matemática entre el tamaño de un inmueble y su costo comercial.  
Lenguaje: Python.  
Modelo: Regresión Lineal (Scikit-Learn)
Contexto: Datos representativos de ciudades como Bogotá, Medellín y Cali en estratos medios.  


🛠️ Herramientas Utilizadas
Para este análisis se emplearon las librerías estándar  
Pandas: Para la manipulación y organización de datos en tablas. 
Scikit-Learn: Para la creación y entrenamiento del modelo de predicción.  
Matplotlib: Para la generación de gráficas y visualización de la línea de tendencia.
